# Goriva.online Chrome Extension

Самостоятелен Chrome extension за бърз преглед на цените на горивата в България.

## Какво прави

- показва средна, най-ниска и най-висока цена;
- позволява избор между София, Пловдив, Варна, Бургас, Русе и Стара Загора;
- позволява избор между A95, Дизел, LPG, A100, Дизел + и Метан;
- показва до петте най-изгодни обекта за избрания град и продукт;
- показва датата на последните налични публикувани данни;
- отваря съответната градска страница в goriva.online;
- запазва избраните град и гориво;
- използва кратък локален кеш, за да не прави излишни заявки.


## Локално тестване

1. Отвори chrome://extensions.
2. Включи Developer mode.
3. Натисни Load unpacked.
4. Избери root папката на това репо, в която се намира manifest.json.
5. Натисни иконата на extension-а и избери град и гориво.

При проблем отвори Inspect views за popup-а или service worker-а и провери конзолата.

## Пакетиране

За публикуване в Chrome Web Store ZIP файлът трябва да съдържа директно:

- manifest.json
- popup.html
- popup.css
- popup.js
- service-worker.js
- папките icons/ и assets/

Не пакетирай целия Git репо като вътрешна папка; manifest.json трябва да бъде в корена на ZIP файла.

## Поверителност

Extension-ът не събира профилни, рекламни или аналитични данни. В Chrome Storage се запазват само избраният град, избраното гориво и кеширан резултат от публичния ценови източник.

## Лицензиране и брандинг

Преди публично публикуване провери правата за използване на логото и името goriva.online в Chrome Web Store.
